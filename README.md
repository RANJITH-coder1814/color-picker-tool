# color-picker-tool
A simple Color Picker Tool built using HTML, CSS, and JavaScript. It allows users to pick a color and copy the HEX color code instantly. This is a useful project for beginners learning DOM manipulation and event handling.

A simple Color Picker Tool built with HTML, CSS, and JavaScript that lets users pick a color and copy the HEX code.

## Features
- Select color using color picker
- Display HEX color code
- Copy color code button
- Live background preview

## Technologies
- HTML
- CSS
- JavaScript

## How to Run
1. Clone the repository
2. Open `index.html` in your browser
